# Product requirements document — BioForge

## Positioning
**Product:** Self-hosted link-in-bio site generator  
**Target users:** Creators, freelancers, musicians  
**Primary user journey:** A user builds a branded bio profile, exports a static website, and publishes it on their own domain.

## Minimum shippable functionality
1. Profile editor.
2. Social links.
3. Reordering.
4. Accessible theme presets.
5. Live responsive preview.
6. Custom seo.
7. Qr code to exported page.
8. Zip export with html/css/assets.
9. Json backup/restore.

## Non-goals & honest limitations
Do not claim public profiles sync across devices; no hosted multi-user accounts; export is a static webpage.

## Core experience
- A visitor can try the principal workflow without an account or external API keys.
- Core output is usable, downloadable, printable or deployable depending on product.
- User receives clear success, validation, empty, failure, undo and data-loss states.
- Mobile, keyboard and assistive technology journeys are included.
- Only features genuinely built and tested appear as functional marketing promises.

## Repo release requirements
Public open-source repository, real implementation, MIT compatible code, fully tested README and Docker without DB, English SEO landing pages, real Hostinger badge after confirming URLs and terms.
