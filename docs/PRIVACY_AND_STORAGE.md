# Privacy and storage model — BioForge

By default processing is browser-only or stateless. No external database, server-side user account, cloud backup or remote analytics is configured. Browser local storage can be erased and does not synchronize devices. User-created exports should be stored securely by the user. If a backend is enabled in a future release, rewrite this page to explain new processing accurately, collect appropriate consent and revisit security policies. Do not claim public profiles sync across devices; no hosted multi-user accounts; export is a static webpage.
