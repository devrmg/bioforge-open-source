# Search discoverability checklist

- [ ] Correct language tag and clean HTML metadata.
- [ ] Product core benefits and limitations stated accurately.
- [ ] Indexable pages have unique useful copy, no duplicate or thin programmatic pages.
- [ ] Dynamic app state isn't unintentionally indexed.
- [ ] Canonical URLs and hostnames match real deployed production domain.
- [ ] robots.txt / sitemap.xml generated with actual published URLs.
- [ ] OG/Twitter preview based on owned actual images.
- [ ] Relevant schema only; all values truthful, no fake stars/prices.
- [ ] FAQ useful to humans; llms.txt documented as optional only.
- [ ] Fast mobile load, optimized assets, accessible controls.
- [ ] Deploy/referral CTA measured ethically; affiliate relationship disclosed.
