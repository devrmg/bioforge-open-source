# Project-local English editorial and conversion copy quality

Write like an experienced human product editor. Specific verbs, clear benefit, honest limitations, meaningful CTAs, real screenshots and useful documentation. Remove robotic filler, emoji overload, repetitive feature triplets, fake testimonials, false scarcity, unsubstantiated social proof, generic `revolutionize/unlock/seamless` language. Edit for actual user jobs and accessibility. Affiliate/referral disclosures should be conspicuous and accurate. Have a second pass specifically eliminate AI-like sameness.
