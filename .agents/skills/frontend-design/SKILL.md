# Project-local frontend design checklist

Use a clear restrained brand identity. Favor strong hierarchy, beautiful spacing, typography that feels designed rather than templated, purposeful illustrations/icons and consistency across pages. Create unique layout patterns appropriate to the product, avoid cliché purple gradient hero sections everywhere. Use screenshots only from working UI. Check mobile at 375/768/1440px, actual keyboard focus, dark-mode contrast (if offered), error/loading/empty states, semantic navigation and reduced motion. Document design tokens and component conventions.
